# 曜日 #

* 開発者: Abdel, Noelia.

このアドオンを使用すると、選択した日付に対応する曜日を調べることができます。

NVDAの「ツール」メニュー内に「曜日」という名前のサブメニューが追加され、そこには2つの項目が含まれています：

* 1つ目の「曜日の検索」は、3つのコントロールで構成されるダイアログを開きます：

    * 日付を選択または入力するためのリストボックス；
    * 曜日を含むメッセージボックスを表示するための「OK」ボタン；
    * ダイアログを閉じるための「キャンセル」ボタン。

* 2つ目の「曜日アドオンの設定」は、日付フィールドのラベルを読み上げるかどうかを指定するアドオンのパラメータを開きます。これは以下の要素で構成されています：

    * 日付選択のアクセシビリティを有効にする；
    * ラベルの読み上げレベル（3つの選択肢があります）：

        * 詳細（デフォルトの選択肢です）；
        * 簡潔（短いアナウンス用）；
        * なし（ラベルの読み上げを無効にします）。

    * 垂直方向に移動するときに、現在の日付フィールドの値のみの読み上げを有効にする；
    * 設定を保存するための「OK」ボタン；
    * キャンセルしてダイアログを閉じるための「キャンセル」ボタン。

## 注意事項 ##

* これらのダイアログは Escape キーを押すだけで閉じることができます；
* 「入力ジェスチャー」メニューの、より正確には「曜日」カテゴリで、これらのダイアログを開くためのショートカットを割り当てることができます；
* NVDA 2018.2 以降を使用している場合、ツールメニューには曜日を検索するための項目が1つだけ表示され、アドオンの設定は NVDA の設定パネル内に配置されます。

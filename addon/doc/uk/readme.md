# День тижня #

* Розробники: Abdel, Noelia.

Цей додаток дозволяє дізнатися день тижня, який відповідає вибраній даті.

Він додає підменю в меню «Інструменти» NVDA під назвою «День тижня», яке містить 2 пункти:

* Перший, що називається «Пошук дня», відкриває діалогове вікно, яке складається з 3 елементів керування:

    * Список для вибору або введення дати;
    * Кнопка «OK» для відображення вікна повідомлення, що містить ваш день;
    * Кнопка «Скасувати» для закриття діалогового вікна.

* Другий, що називається «Налаштування додатка dayOfTheWeek», відкриває параметри додатка для визначення того, чи хочете ви озвучувати мітки полів дати чи ні. Він складається з таких елементів:

    * Увімкнути доступність засобу вибору дати;
    * Рівень озвучування міток, при якому у вас буде 3 варіанти на вибір:

        * Довгий (це вибір за замовчуванням);
        * Короткий (для коротких сповіщень);
        * Вимкнено (щоб вимкнути озвучування міток).

    * Увімкнути озвучування тільки поточного значення поля дати при переміщенні по вертикалі;
    * Кнопка «OK» для збереження вашої конфігурації;
    * Кнопка «Скасувати» для скасування та закриття діалогового вікна.

## Примітки ##

* Ви можете закрити ці діалогові вікна, просто натиснувши клавішу Escape;
* Ви можете призначити комбінацію клавіш для відкриття цих діалогових вікон у меню «Жести вводу» і, точніше, у категорії «День тижня»;
* Якщо ви використовуєте NVDA 2018.2 або новішу версію, ви знайдете лише один пункт у меню інструментів для пошуку дня, а налаштування додатка будуть у панелі налаштувань NVDA.

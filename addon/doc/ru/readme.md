# День недели #

* Разработчики: Abdel, Noelia.

Это дополнение позволяет узнать день недели, соответствующий выбранной дате.

Оно добавляет подменю в меню «Инструменты» NVDA под названием «День недели», содержащее 2 пункта:

* Первый, называющийся «Поиск дня», открывает диалоговое окно, состоящее из 3 элементов управления:

    * Список для выбора или ввода даты;
    * Кнопка «OK» для отображения окна сообщения, содержащего ваш день;
    * Кнопка «Отмена» для закрытия диалогового окна.

* Второй, называющийся «Настройки дополнения dayOfTheWeek», открывает параметры дополнения для указания того, хотите ли вы озвучивать ярлыки полей даты или нет. Он состоит из следующих элементов:

    * Включить доступность средства выбора даты;
    * Уровень озвучивания ярлыков, при котором у вас будет 3 варианта на выбор:

        * Длинный (это выбор по умолчанию);
        * Короткий (для кратких оповещений);
        * Выключено (чтобы отключить озвучивание ярлыков).

    * Включить озвучивание только текущего значения поля даты при перемещении по вертикали;
    * Кнопка «OK» для сохранения конфигурации;
    * Кнопка «Отмена» для отмены и закрытия диалогового окна.

## Примечания ##

* Вы можете закрыть эти диалоговые окна, просто нажав клавишу Escape;
* Вы можете назначить комбинацию клавиш для открытия этих диалоговых окон в меню «Жесты ввода» и, точнее, в категории «День недели»;
* Если вы используете NVDA 2018.2 или более позднюю версию, вы найдете только один пункт в меню инструментов для поиска дня, а настройки дополнения будут находиться в панели настроек NVDA.
